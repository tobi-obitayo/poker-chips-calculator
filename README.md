# Stacked

Stacked turns a poker buy-in and a box of chips into balanced player stacks. It
favors more low-value chips, suggests starting blinds, handles leftover chips,
and can trade an exact buy-in for cleaner denominations.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed in the terminal.

## Checks

```bash
npm run lint
npm run build
```
